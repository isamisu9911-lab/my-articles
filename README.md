# My First Steps with GitHub

Today I created my first GitHub repository, and it was much easier than I expected. In this article, I want to share what I learned as a complete beginner.

## What is GitHub?

GitHub is a [website where people](https://shamsulisam.com) store, share, and collaborate on projects. It started as a place for programmers to keep their code, but today people also use it to publish articles, notes, and even full websites.

## What is a Repository?

A repository, or "repo", is like a folder for your project. It keeps all your files together and remembers every change you make. If you ever make a mistake, you can go back to an older version.

## How I Created My First Repository

1. I signed in to my GitHub account.
2. I clicked the "New repository" button.
3. I gave it a short name and chose Public visibility.
4. I turned on the README option and clicked "Create repository".

That's it. My repository was ready in less than a minute.

## Why Markdown is Great

GitHub uses Markdown, a simple way to format text. A `#` makes a heading, `**text**` makes text bold, and a dash at the start of a line makes a list. You don't need to be a programmer to learn it.

## What's Next?

Now that my repository is ready, I plan to publish more articles here and slowly learn more about GitHub, like branches and pull requests.

If you are new to GitHub, my advice is simple: just start. Create a repository, write something small, and publish it. You will learn the rest along the way.
